CriScope · 游戏接入与日志位置
========================

1. 运行本目录的 CriScope.exe。软件监听 TCP 18961，游戏可在同机或局域网中连接。
2. Unity 工程须已接入 CRIWARE。解压本目录 UnitySDK/ 中的独立 SDK 接入包，
   运行 install.py 选择 runtime 或 editor 配置，复制完整实现及 .meta；不要只复制旧版四个脚本。
   SDK 自带版本、清单与同步校验；游戏只保留 GM/菜单及音频初始化适配。
   完整实现与版本说明见接入包 README.md 或源码仓库 integrations/unity/README.md。
3. 仅在 Unity Editor、Development Build 或明确启用 CRISCOPE_DIAGNOSTICS 的
   调试构建中，等 CRI Atom 初始化后从主线程调用：

       CriScope.Unity.CriScopeDiagnostics.Connect("127.0.0.1");

   跨机器连接时改为运行 CriScope 的电脑地址。关闭时调用 Disconnect()。
   可读取 CaptureEnabled、Host、Status 查看连接状态。

可以把 Connect()/Disconnect() 接到游戏已有的调试菜单；无需给播放、暂停、
AISAC 等业务接口增设采集点。采集实现应放在实际运行的客户端工程中。
已加载的 CriAtom.cueSheets 会分批提供 Cue 配置分类、标注时长、Pan Type
和衰减距离范围（需更新游戏侧接入代码）。连上之前已在
播放的 Cue 也可按 ACB 句柄与名称匹配；不代表运行时覆盖分类。通过业务代码
直接加载、未注册到 CriAtom.cueSheets 的 ACB 不在此目录采集范围内。

原生 Monitor 使用游戏电脑自己的 TCP 2002/2003；桌面接收端不按 IP 限制进程数。
Atom Viewer 等试听工具即使没连过 CriScope，也可能先启动这两个原生端口。
SDK 1.0.2 会显示冲突程序名、PID 和游戏电脑名。释放该工具的原生预览端口后，
会自动重试启动 Monitor 与原生连接，不必重开游戏采集开关。
原生未就绪时仍可接收 SDK 补充信息。不要把 2002 映射成远端共享端口。

客户端卡片出现和消息数增长，只表示桥接已接入并收到数据。
播放轨道依赖原生 CRI Monitor；SDK 内存、资源采样不会生成播放轨道。
原生通道未就绪时，卡片与顶部会明确提示，轨道区域显示具体失败原因；
底栏分别统计原生和 SDK 消息。原生已连接但还没有播放事件时，轨道区域
会提示查看“事件日志 → 异常与连接”或“播放相关（全部）”。
未知 CRI DLL 的热启动、端口所属进程和协议兼容问题仍需按诊断处理。

连接建立后，CriScope 自动按通道创建物理日志：

       <本目录>\.local\recordings\

菜单“打开日志目录”可直达此处；“导入日志…”以只读历史会话打开 .criscope 文件。
可通过环境变量 CRISCOPE_DATA 指定其他日志目录。实时视图只保留近期内存窗口，
更早的数据从物理日志导入查看。Bus 性能快照仅由 Cue、Voice 或控制事件触发
写盘，导入后的资源曲线属于稀疏采样。

空间页：滚轮缩放；拖拽空白处或中键拖拽平移；F 或全览按钮恢复全图，
C 或耳朵按钮定位监听器。进入时全览一次，之后固定取景；新增画外对象会提示按 F。
空间缩放不会改变历史时刻或停止采集。播放状态和 Cue 文字不会改变对象排布槽位。
地图常态以图标和一行 Cue 名显示；有明确活动 Voice 的音源亮色，空闲或状态
未确认的音源灰色。上次 Cue 标为“上次”，无关联记录时只显示图标。
地面俯视使用 XZ 等比例投影，Y 为高度。实点始终处于真实坐标，拥挤时图标和
Cue 标注通过细引线避让；实线选中圈、虚线历史圈均位于坐标点，不随标注偏移。
监听点使用独立蓝色；同坐标音源和监听点共用实点并保留蓝色外环。
选中音源可查看到监听点的参考水平距离；Hover 同时显示水平距离、高差与三维距离。
未确认的绑定明确标为参考。地图上的水平距离不代表最终衰减增益。
Hover 查看类型、坐标与完整 Cue；同点对象用数量角标，点击可展开。
点击空闲音源，抽屉可查看上次 Cue，并在实例仍保留时跳回播放轨道。
选中声音轨道，抽屉“播放时空间状态”提供 Cue Pan Type、开始及结束前的
音源位置、监听点与三维距离。点击“查看结束前空间”显示虚线历史影子；
点击“返回实时”退出。坐标单位不自动视为米，未确认绑定的距离标为参考。
位置保留原始采样时间；未采到的位置和旧日志缺失的 Pan Type 显示未记录。
历史距离仅是排查线索，停止原因需结合抽屉里的结束原因与请求停止记录。

发布时请分发完整版本文件夹或 ZIP，不要只复制 EXE。
