# 2026-10-15 界面改造

这一版以浅色为初始主题，重新组织导航、工具栏、时间线与详情抽屉。浅色采用暖灰与低饱和绿色，深色采用炭灰分层；类别颜色保留在数据上，普通结束状态使用中性色。主题切换会持久保存，且不覆盖时间轴偏好。

## 主要变化

- 工作区使用文字页签和细下划线；当前连接身份、采集状态与导出入口集中在顶部。
- 导出问题包、暂停跟随、返回实时等操作保留文字；关闭、全览、主题、详情开关和定位采用统一图标，并保留提示、无障碍名称与焦点反馈。
- 时间线增加行高与名称字号，选中轨道用浅底色和边线标识，保留原有 Category 颜色。
- 抽屉按状态、观测历时、结束原因、时间记录、声音信息和关联操作排列。技术字段默认折叠，长名称仍可选择复制；未完整记录的时长以普通提示显示。
- 历史记录的移动视窗操作改为“自动浏览”，实时视图使用“暂停跟随／返回实时”，避免被理解为播放声音或停止采集。
- 底栏合计同次采集的原生与 SDK 通道接收量及缺失量。
- 应用 PNG 导出按逻辑尺寸渲染，修正高 DPI 下自绘面板裁剪错位；不改变实际窗口的系统缩放。

## 验证

- Release 编译和 Windows x64 自包含发布成功。
- UI 检查 259/259 通过，覆盖主题切换、偏好持久化、窄窗口、详情折叠、复制、定位返回和时间轴交互。
- 播放模型检查 50 项通过；Agent 接口检查 9/9 通过。
- 使用最终发布的 EXE 连接已运行的 Windows 游戏，接收原生与 SDK 两个通道，观察已有背景音乐，并调用游戏现有音频方法触发短音效。
- 实际记录包含自然结束和播放数量限制；分别检查了两种主题、六个工作区和详情内容。截图由应用自身渲染，操作系统截图服务在本次环境中超时，未作为验证依据。
- 完成后关闭游戏侧采集，保留游戏和新版工具运行。新版窗口停留在浅色声音时间线，保留实测记录供人工验收。

本次连接原生通道报告缺失 0 条，SDK 通道报告缺失 7 条。该采集侧现象尚未修复，界面会显示合计缺失量。空间页验证了已记录对象的显示；本次 UI 短音效没有关联空间音源，未把它作为真实空间跳转成功的证据。

## 本地交付

- `artifacts/CriScope-v008-win-x64/CriScope.exe`：最终运行目录，保留完整目录一起使用。
- `artifacts/CriScope-v008-win-x64.zip`：自包含分发包，已检查不包含本地录制与日志。
- `.local/diagnostics/`：本机验收材料，含两种主题截图、UI 检查结果及发布校验。旧版本录制归档在 `.local/archived-version-data/`，不随分发 ZIP 发布。

记录是音频诊断数据，不包含可回放的声音。当前运行窗口保留了两个通道合并后的显示；重新导入时，原生与 SDK 日志分别作为独立历史会话查看，当前版本不会自动合并历史通道。原生文件用于检查播放与结束原因，SDK 文件用于查看补充指标和元数据。
