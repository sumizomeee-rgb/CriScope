# v0.10 — 视觉语义与信息层级

## 已实现

- `VisualLanguage` 集中定义 `IconKind`、`SemanticColor`、固定画布 SVG 和事件标记组件；主题色由 `Palette` 映射。导航按钮显式声明动作与关联名称，不从文案猜测目的地。
- 控制筛选、日志事件和空间对象使用公共图标；事件类型沿用固定颜色，Sequence 标签仍有独立稳定配色。日志选中改为柔和底色与侧边线。
- 控制子行统一两行，关联 Cue 与定位图标对齐，不再因单个关联增加行高。多个关联实例显示数量，显式展开后逐项定位，编号独立保留。
- 实例抽屉标题保留编号，标题下显示原生 `Acb Name`，标注为 CueSheet / ACB；它不被当作 Unity 注册别名。播放历时与 Cue 时长用双列摘要突出，Category 后置。
- 播放中的空结束行不再显示。真实开始/结束分别使用绿色/红色，未知开始不使用绿色。没有 Voice 的待播放实例显示“尚未开始”。
- 日志展示事件类型、发生时间和所属声音，关联播放概况固定在事件时刻；不随实时位置累计。修复外部定位后日志高亮与详情不一致。
- 热接入已有播放显示“接入时已在播放”，从“请求播放”筛选排除。保留兼容的内部事件表示与实例关联。
- 一个“更多信息”入口内，Player 与 Voice 合并摘要，关联记录最多预览三条，可进入带明确可退出筛选的事件日志查看全部关联记录，包括 Player 上的 AISAC 设置。
- 日志工具栏在窄窗口换行；长关联名与实例编号分开，保证定位与身份不被名称挤走。

## 验证

- Release 构建、Windows x64 自包含发布。
- 152 项 UI 检查：涵盖历史事件时间口径、热接入分类、ACB 名称、刷新下展开保留、长名称同名多实例、1000 px 窄窗口、关联记录预览及查询。
- 25 项播放语义检查通过。
- 软件自身截图：深浅主题为测试夹具；同名并发与长名称为测试夹具；`live` 截图来自实际 Unity 连接。

## 保留边界

本轮未修改游戏业务或 SDK 采样。短音效仍可能因 SDK 最新播放采样没有 Cue 时长；不拿实际播放历时代替。ACB 名称不保证等于游戏注册的 CueSheet 别名。原始字段仍保留在更多信息底部；本轮没有重构采集丢失统计。

图标与语义色基础库已应用到上述主要入口，不宣称所有自绘图元已经完全迁移。窄窗口与交互测试不等于完成全面可用性验收，交付后继续评审目的地可预测性、信息密度与关联记录入口。
