# v0.6.0：停止语义、空间浮层与详情布局

## 本轮交付

- 客户端选中框恢复；导航采用浅底与紫色下划线，录制空闲为中性样式，录制中使用红点。返回按钮明确写为「返回」，没有历史时隐藏。
- 详情改为两列属性表，Category 分别显示为可筛选标签。点击控制/回调先看该条内容，所属播放概况收进折叠区；原始字段和时间解释保留在次级区域。
- 实时日志默认按播放实例显示开始，多个 Voice 不重复生成多个开始；「声部明细」保留各 Voice 分配与释放。底部明确显示当前缓存、匹配数、截断及暂停状态。
- 原生停止请求与实际实例结束分开：请求停止时仍有 Voice 会显示「停止中」，不能把调用 Stop 当成立即结束。自然结束、Player/Playback 主动或立即停止、播放数量限制有相应原因；混合/未知原因不猜测。
- 空间同点展开列表改为独立浮层，可关闭、Esc、滚轮和拖动滚动条。浮层不被监听点标签覆盖，不穿透点击；其上禁用干扰 tooltip。标签避让，真实坐标锚点保留，增加 +X/+Z 与坐标单位。
- 修复 Source/Listener Update 包旧快照覆盖新位置的问题：设置进入待提交状态，在 Update 时应用。衰减点位置与 Focus 参数同时提交。

## 数据边界

- VoiceStopReason 数字含义与空间提交模型仅对已验证 SDK `2.28.272-0.5` 启用。其他版本保留原生证据，不生成未经验证的停止原因和空间位置。通用 Stop 函数请求仍可记录。
- 热接入前未收到设置的位置不会补造。Cue 标注时长与实际 Voice 播放历时分别显示；没有完整开始/结束记录不会伪造历时。
- Live 缓存仍有 120 秒 / 120,000 事件边界。长时间暂停日志后无法补回已经逐出的部分，持久调查需提前录制。
- 本轮未修改 Unity 接入或增加业务采集点；未改变采集关闭行为，也未重新构建游戏 Release 包。

## 验证

- UI 实际窗口 125 项通过：详情折叠、两列表格、卡片选中、双向导航、日志归并、30 个同点音源浮层及标签避让等。
- Core 12、Playback 25、Bundle 16、Agent API 9 项通过。
- Native / Spatial 专项通过：停止原因、精确实例身份、版本边界、旧坐标快照、提交时序、Focus、重置与销毁。两份本地真实协议帧夹具回归通过。
- 发布的自包含 Windows x64 EXE 已启动，当前 Unity Editor 的原生和 SDK 通道自动接回同一客户端卡片；应用级 PNG 截图端点正常。
- 真实运行截图与合成压力场景分别保留在本地；不把合成测试图当成游戏实测。
