# v0.7.0 交互整理

- Category 仅展示归属，不可点击，不改变时间线筛选。
- 详情的请求播放、开始、请求停止、结束与日志发生时间改为毫秒钟表时间。`≈` 表示会话接收锚点换算；跨采集日期补日期，缺锚点不伪造时间。历时仍由原始事件时间计算；时间尺保留采集相对时间。
- Cue 身份去重，结束原因与触发实例分开。资源、Player 和 Voice 放入次级折叠区，默认轨道不显示 Voice 数量；从详情「播放器与 Voice」选择「查看 Voice 轨道」。
- 折叠标题统一轻量整行样式，实时刷新保持展开状态。历史控制/回调的播放概况按事件时刻取状态。
- 打开录制和导出问题包收进顶部更多菜单；主题按钮为太阳/月亮矢量图标；关联跳转统一定位图标；空间图层使用音源/监听 SVG 路径。
- 日志新增请求播放、开始播放、请求停止、播放结束直接筛选；Voice 明细显示分配/释放。
- 实时采集初期缩短可视跨度，减少尚未采集的负时间空白；未知起点改为截断端点。

验证：127 项实际窗口检查通过，包括 Category 非交互、时钟换算、停止筛选及抽屉刷新。发布版接回现有 Unity 原生/SDK 通道，以软件截图接口检查暗色详情和空间。未修改游戏侧采集代码或 CRI 协议解析。
