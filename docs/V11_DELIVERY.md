# v0.11 — 详情操作与空间视图稳定性

- Cue 标题和 CueSheet / ACB 名称支持选择文本、右键复制完整名称。ACB 名称仍不等同于 Unity 注册别名。
- Category 标签与右侧首行顶对齐，换行只占用值列。
- 结束因果信息改称“由谁触发”，定位图标紧挨对应实例；仅在有明确关联记录时提供跳转。
- 普通定位入口排列为紧凑一行，窄宽度自动换行；更多信息折叠缩小字号及高度。
- 日志筛选项与选中项使用公共 SVG / 颜色组件。AISAC 与 Selector 的对象列显示实际 Player / Category，参数留在内容列。
- 空间同点列表改为覆盖层，开关不再改变绘图区宽度、缩放及对象坐标。
- 控制关联 Cue 有独立背景，选中时间竖线避让名称区域。

验证：158 项 UI 检查、25 项播放语义检查通过，Windows x64 自包含发布成功。UI 检查包含空间列表开关坐标一致、可选择名称和复制菜单、首行对齐、AISAC 对象以及筛选模板。截图中的 fixture 为测试数据。

边界：本轮未调整采集及 SDK。短 Cue 时长采样缺失仍可能发生；结束原因也只呈现已有证据，不推断缺失原因。空间列表开关稳定不等于整个窗口调整尺寸时锁定相机。日志详情分类与冗余信息仍有进一步统一空间。
