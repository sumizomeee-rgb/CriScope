# v0.5.0：对象联动与实时事件日志

## 操作入口

- 声音时间线详情的「在空间中查看」选择实际关联的 CRI 3D Source；空间详情的「声音轨道」返回具体 Playback，同名 Cue 不作为关联键。
- 单个音源直接定位，多个音源分别提供入口。同点聚合自动展开；目标有短暂加粗描边，随后保留选中底色。左上角返回箭头恢复上一视图、时间范围、筛选、展开项和滚动位置。
- Player 控制子行直接显示当前时刻关联的 Cue 标签，按播放开始顺序排列。标签可跳至具体实例；完整关联在详情中列出。控制值仍归 Player，不把同名 AISAC 混成一个值。
- 五类控制事件各有固定颜色；Sequence 标签使用独立的稳定字符串色。颜色不是声音状态、音量或播放成功的证据。
- Category 名称来自原生配置，归属来自原生 Category/Playback 计数事件。允许多个 Category，点击详情标签筛选声音轨道。热接入没有收到归属时显示「未收到归属」，缺少配置时显示索引；不把 Bus 当作 Category。
- 事件日志直接查看当前缓存，输入「开始播放 CueName」「停止 CueName」「AISAC」等空格分隔关键词；全部词均须匹配。分类支持播放、控制、回调、诊断。
- 日志最新在上，滚动时暂停列表刷新但继续采集；「继续实时」补上期间记录。单击查看详情，双击定位对象轨道。默认最近 1000 条匹配，可增加至 20000 条；底部显示匹配总数。打开已保存日志可搜索录制，不必手工翻 JSON。
- 日志搜索独立于时间线搜索；实时日志也独立于时间轴历史窗口。记录日志、导出问题包继续用于持久保存和分享。

## 数据与交互边界

- 位置归属依赖原生 Voice→Playback→3D Source 关系，保留桥接 epoch，不能跨采集段合并。
- 空间联动取所看时刻的数据，不能拿未来位置补历史。没有空间关联不等于已确认是 2D。
- 导航可临时显示被当前筛选隐藏的目标，工具栏明确标记，可取消或返回。此操作不改变游戏采集状态。
- Category 当前是观测到的播放归属；连接前的分配不会凭空补齐。已有旧版日志未包含结构化 Category 时不会猜测归属。
- 本轮没有增加游戏业务方法打点，也没有修改 Unity 接入代码。新增 Category 投影在桌面端处理原生包。
- 本机受控测试发现一次 Source SetPosition 与紧随其后的原生 Source Update 包坐标不同。界面目前保留最新原生包坐标及原始证据；尚未确认两类包的准确提交语义，不把该测试当成空间坐标精度验证。

## 验证

- Avalonia 实际窗口 UI 测试 116 项：同名实例、epoch 隔离、历史位置、双向导航与多级返回、Category 筛选、日志搜索与暂停补齐、抽屉展开保留。
- Core 12 项、Playback 25 项、问题包 16 项、Agent API 9 项通过；空间与 CSB3 桥接回归通过。
- 原生解析通过 Category 身份/未知名称/采集段重置测试，以及两份真实协议录制回归。
- Unity Play Mode 受控静音 UI 播放保留 Voice，观测到约 0.901 秒历时及两个 Category。确认播放→空间→播放往返保留历史时刻。临时 Player、3D Source、ACB 已释放。
- 本地测试、截图、录制及调查脚本位于忽略的 `.local`，不进入发行 ZIP。

## Agent 接口

新增 `POST /ui/action`：`navigate`（value 为 `space` / `playback`，先选择事件）、`back`、`log-search`、`log-follow`（true/false）。多目标导航要求用户在详情中选目标，API 不自动挑第一个。

`workspace:Logs` 打开完整事件日志；`diagnostics` 显示/隐藏底部日志面板。`/ui/state` 返回 Category 筛选、导航层数、日志搜索和日志跟随状态。截图继续使用应用级 `/screenshot`。
