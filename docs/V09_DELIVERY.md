# v0.9：统一信息与操作

本轮统一详情抽屉、关联跳转和日志浏览的交互。主界面以 Cue 为中心，播放历时和 Cue 配置时长保持一级可见。

- 抽屉属性行最低 28 px；主要定位操作集中排列，按钮 32 px。开始播放使用绿色，结束/停止使用红色，同时保留文字标签。
- 播放请求、播放器、Voice、关联控制和原始字段统一放入“更多信息”，不再嵌套多个折叠。空间坐标的技术解释同样放入次要信息。
- 控制页 Cue 名称为信息文本，旁边的独立 SVG 按钮才执行跳转；实例编号用于区分同名播放。控制分组使用方向箭头表示展开。
- 抽屉的多目标关联显示名称与独立定位按钮，避免长 Cue 名称撑高按钮。控制记录同样将信息与定位分开。
- 按钮图标使用明确的枚举配置，不再根据文案包含“播放”等词猜测图标。
- 日志行提供定位图标；“播放相关（全部）”明确表示生命周期分类集合。向较旧日志滚动时暂停刷新，向最新方向滚动不再误触暂停。
- 返回实时保留当前时间范围；点击时间线空白处只清除选择，不关闭抽屉。空间和混音隐藏不适用的时间范围和全览按钮；混音滚轮不再意外改变时间范围。

## 验证

- Release 发布成功，完整自包含 Windows x64 包已更新。
- 140 项 UI 检查通过，包括深浅主题折叠刷新、单一更多信息、定位集中和同名实例跳转。
- 25 项播放语义检查通过。
- 真实 Unity 连接自动恢复，核对客户端卡片、播放详情和事件日志；截图由软件自身截图接口生成。

## 已知限制

SDK 当前每 500 ms 读取组件最新播放，短音效可能没有 Cue 元数据。本轮修复同实例晚到元数据被详情时间过滤的问题，但没有实施 ACB 资源目录采集，也不以播放历时代替 Cue 时长。游戏 SDK 和业务代码本轮未改动。

返回实时保留全览产生的大范围；需要缩小窗口时选择最近 10 秒、30 秒或 2 分钟。日志恢复实时仍使用明确按钮，未引入滚到顶部自动恢复。

本轮优先统一已存在的交互，不宣称完成全量可用性验证。交付评审应继续关注长名称、多目标关联和窄窗口下的可发现性。
